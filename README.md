# Pix AI

واجهة Pix متصلة بمحرك Gemini scraper الأصلي الموجود في `src/lib/scrap/ai/gemini.js`. لم يتم استبدال المحرك بـ API تجاري أو ردود محلية تجريبية.

## دليل المطوّر

قبل البدء في تعديل المشروع، اقرأ [DM.md](./DM.md) لفهم البنية وتدفق الطلبات ومتطلبات التشغيل والاختبارات وحدود النظام.

## التشغيل المحلي

يتطلب Node.js 20 أو أحدث.

```bash
npm test
npx vercel dev
```

ثم افتح عنوان Vercel المحلي. الواجهة تستدعي `/api/chat` من نفس النطاق، والخادم يستدعي محرك Gemini.

## النشر على Vercel

- Framework: Other
- Build Command: اتركه فارغاً
- Output Directory: `.`
- Node.js: 20.x أو أحدث
- يمكن ضبط `ALLOWED_ORIGIN` على رابط الموقع النهائي.

## ملاحظات تشغيلية

- هذا المشروع يستخدم سكربت Gemini Web المرفق كما هو، وليس Gemini API الرسمي بمفتاح Google.
- السكربت يعتمد على واجهات Gemini الداخلية غير الموثقة؛ قد تتغير أو تفرض Google قيوداً، لذلك لا يمكن ضمان استمرارية الاتصال.
- لا توجد مفاتيح API مطلوبة في الواجهة.
- يوجد حد طلبات مؤقت داخل ذاكرة عملية الخادم؛ وهو حماية أولية وليس نظام حصص موزعاً.
- محادثات الواجهة تحفظ محلياً، ويُحفظ معرّف جلسة Gemini مع كل محادثة لاستكمالها.
